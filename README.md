# エンジニア日誌プロジェクト

本プロジェクトでの開発においてのAIの立ち位置
  本プロジェクトでは、コーディング・設計において、AIをレビュアーおよびサンプルコード生成用として使用しました。
  また、単体試験ではAI生成コードをRVする方式で試験を行いました。

  このような開発方法をとった理由としては以下の通りです。
	初学者がバイブコーディングおよびAI生成コードをRVする方法でのコーディング・設計を行った場合に、	
		・コーディングする上で実装するために何が必要でどんな手順で作ればいいという**問題解決能力**が身につかない。
		・設計を行う上で何がどのくらいの時間で実現可能かなどの**勘が身につかない**。
  という問題があります。
  つまり、生成されたコードを読むだけでは知識の蓄積になるが、エンジニアとしての本質的な思考能力が身に付かないと考えました。
	以上の理由から、本プロジェクトはAIを補助的な役割として限定的な使用にとどめています。

	ではなぜ試験ではAIコーディングを行っているかというと。
		今までやってきたコーディングは「何を作るか」という**設計力・実装力**が問われる。
		テストコードは「すでに作ったものが正しいか検証する」作業であり、テスト設計の観点（正常系・異常系・境界値）を理解してレビューできれば、ゼロから書く必要性は本質的には低い。
以上のことからテストコード生成はAIに任せて、それをRVする形で試験を行っていきます。

	
	
単体試験方法として、
  1. claude試験項目表を生成。
  2. テスト対象ロジックのふるまいを理解し、試験項目に不備がないか確認。
  3. 生成されたテストコードと試験項目表を比較して、テストコードに不備がないか確認する。
